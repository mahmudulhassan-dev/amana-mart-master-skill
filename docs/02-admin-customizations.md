# Amana Suite Admin Panel Customization & Translation Guide

## 1. Landing Page Redirection & Customization
By default, the Amana Suite backend provides a landing page at `https://amanasuite.com`.

### Landing Page Redirection to Web Portal:
1. Open **Admin Panel > System Settings > Landing Page Settings**.
2. **Redirection Link Option:** Set the redirect URL to your Next.js customer web portal: `https://amanamart.com`.
3. When enabled, any visitor hitting the root domain will be redirected smoothly to `https://amanamart.com`.

## 2. Admin & Store Panel Language Translation (`messages.php`)

### Translation File Location:
- **English Master File:** `/www/wwwroot/amanasuite.com/resources/lang/en/messages.php`
- **Bengali Translation File:** `/www/wwwroot/amanasuite.com/resources/lang/bn/messages.php`

### Rules for Message Translations & Variables:
1. **Preserve Variables:** Words starting with a colon `:` (e.g., `:method`, `:count`, `:store_name`, `:order_id`) are dynamic runtime variables generated by Laravel.
   - Example Key: `'config_account' => 'Config your :method account'`
   - Bengali Translation: `'config_account' => 'আপনার :method অ্যাকাউন্ট সেটআপ করুন'`
2. **Do NOT Modify Keys:** Only modify the value string on the right-hand side of the array (`'key' => 'value'`).
3. **Punctuation Colons:** A colon `:` at the end of a word (e.g., `Ex:`) is literal text, not a variable.

## 3. Brand Theme Customization
To customize Amana Suite brand colors and logos:
1. Navigate to **Admin Panel > Business Settings > Theme Setup**.
2. **Brand Colors:** Set Primary Color to **Neon Mint (`#10F3A2`)**, Secondary Color to **Cyan Blue (`#33B5FF`)**, and Background to **Pitch Black (`#0B0E14`)**.
3. **Logos:** Upload Amana Mart Admin Header Logo (PNG/WEBP), Store Panel Logo, and Favicon.
